## 二、待产品决策（未改，需你拍板）

## 三、规范层面发现（单独列，不与实现问题混排）

1. **字阶缺第三层**：现有 11 / 11.5 / 12 / 12.5 / 13 五档辅助字号，实际视觉差异极小。建议收敛为 12（辅助）/ 14（正文）/ 17（标题）/ 22（大标题）四档。
2. **间距未成体系**：卡片内边距 13/14、列表间距 10/12 混用。建议全站 4 的倍数：8 / 12 / 16 / 24。
3. **圆角五档并存**：9 / 10 / 11 / 12 / 13 / 14 / 15。建议 8 / 12 / 16 三档，超大容器用 20。
4. **颜色语义化不足**：紫色系直接写死 `#8b5cf6 / #7c3aed / #a78bfa` 三处，未纳入 `--brand` token。

## 1. 背景与目标

### 1.1 背景

AI图片创作当前提供 8 项能力（生成白底图、生成场景图、图片变清晰、商品图换背景、AI细节图、AI卖点图、商品智能换色、AI标尺图）。其中「AI卖点图」「AI细节图」面向**商品营销转化**场景，需要比"上传图→出图"更细的参数控制，才能产出可直接投放平台详情页的素材。

### 1.2 目标

1. 让卖家无需撰写文案/排版，输入商品图即可生成**可直接上架的营销卖点图与细节特写图**
2. 通过"卖点类型/突出细节"等可选项，把 AI 的自由发挥收敛到卖家想要的表达维度上
3. 支持多语种批量输出，一套素材铺向多国市场
4. 生成前明确告知积分消耗，失败自动返还

### 1.3 名词约定

| 名词  | 含义                            |
| --- | ----------------------------- |
| 卖点图 | 商品图 + 提炼/排版上去的卖点文案，用于主图与详情页头图 |
| 细节图 | 商品材质、工艺、结构的特写展示图              |
| 张数  | 计费单位，一张成品图 = 一次计费             |

## 2. 页面入口与结构

**路径**：首页 → 分类「AI图片创作」→ 卡片「AI卖点图 / AI细节图」→ 工具表单页

**表单页结构（自上而下）**：

1. 顶栏：返回（回到 AI图片创作分类页）+ 工具名
2. 工具简介（intro）
3. 输出物说明（输出：xxx）
4. 字段组列表（每项：字段名 + 必填星号 + 说明文案 + 控件）
5. 底部计费页脚：左侧「处理内容 N 张 · 共 N 积分」，右侧「开始处理 ⚡N」

## 3. 通用规则

### 3.1 控件类型

| 类型        | 说明          | 交互                 |
| --------- | ----------- | ------------------ |
| upload    | 单图上传框（虚线）   | 点击唤起文件选择，支持格式/大小校验 |
| upload2   | 双图上传框（并排两个） | 用于首尾帧              |
| textarea  | 多行文本输入      | 带 placeholder 示例   |
| chips（单选） | 胶囊标签组       | 点击切换选中，同类互斥        |
| chips（多选） | 胶囊标签组       | 点击切换选中/取消，可全不选     |

### 3.2 通用校验

- 必填项未填：对应字段标红提示，不允许提交
- 图片：格式 JPG/JPEG/PNG；单张 ≤ 25MB；短边 ≥ 300px；数量上限由字段指定
- 文本：卖点关键词建议 ≤ 200 字，超出提示但不阻塞
- 提交时校验积分余额，不足则提示去领取/充值

### 3.3 通用交互状态

| 状态  | 表现                                 |
| --- | ---------------------------------- |
| 生成中 | 底部按钮转"生成中…"并禁用；任务进历史创作，状态=生成中      |
| 成功  | 跳转结果页；历史记录状态=已完成                   |
| 失败  | 历史记录状态=失败；**已扣积分自动返还**，明细记一条蓝色返还记录 |
| 空状态 | 历史创作无记录时显示"暂无创作记录"                 |

## 4. AI卖点图 字段说明

**工具简介**：自动提炼卖点文案，排版生成营销主图  
**输出物**：候选卖点图（含文案与排版）  
**CTA**：开始处理

| # | 字段    | 必填 | 控件            | 取值 / 选项                                          | 默认值 | 校验与说明                                      |
| - | ----- | -- | ------------- | ------------------------------------------------ | --- | ------------------------------------------ |
| 1 | 商品图片  | 是  | upload（限 1 张） | JPG/JPEG/PNG                                     | 无   | 单张 ≤ 25MB，尺寸不小于 300px；建议主体清晰、背景干净          |
| 2 | 卖点类型  | 是  | chips 多选      | 核心功能 / 性能优势 / 材质工艺 / 设计亮点 / 使用场景 / 促销活动          | 全不选 | 可多选，AI 围绕所选类型提炼卖点并排版上图；**不选则自动识别**         |
| 3 | 卖点关键词 | 否  | textarea      | 自由文本                                             | 空   | 示例：「续航 48 小时 · IPX7 防水 · 一年换新」；留空由 AI 自动提炼 |
| 4 | 生图比例  | 是  | chips 单选      | 1:1 / 4:3 / 9:16                                 | 1:1 | 说明：1:1 平台主图 · 4:3 详情页横图 · 9:16 竖版主图 / 详情长图 |
| 5 | 文案语种  | 是  | chips 多选      | 中文 / 英语 / 阿拉伯语 / 泰语 / 印尼语 / 越南语 / 韩语 / 马来语 / 蒙古语 | 中文  | **按所选语言输出整套卖点图，每个语种 1 张，按语种数计**；至少保留 1 个语种 |

**计费**：单价 8 积分/张，出图张数 = 所选语种数

> 示例：选「中文 + 英语 + 阿拉伯语」→ 处理内容 3 张 · 共 24 积分

## 5. AI细节图 字段说明

**工具简介**：放大材质与工艺细节，突出商品品质感  
**输出物**：商品细节特写图  
**CTA**：开始处理

| # | 字段   | 必填 | 控件            | 取值 / 选项                                               | 默认值   | 校验与说明                                   |
| - | ---- | -- | ------------- | ----------------------------------------------------- | ----- | --------------------------------------- |
| 1 | 商品图片 | 是  | upload（限 1 张） | JPG/JPEG/PNG                                          | 无     | 单张 ≤ 25MB，尺寸不小于 300px；高清原图效果更好          |
| 2 | 突出细节 | 是  | chips 多选      | 材质纹理 / 工艺接缝 / 功能按键 / 品牌标识 / 包装细节 / 配件细节 / 内部结构 / 表面处理 | 全不选   | 可多选，AI 围绕所选细节生成特写；**不选则自动识别**           |
| 3 | 展示形式 | 否  | chips 单选      | 单细节展示 / 多细节拼接展示                                       | 单细节展示 | 决定细节图的呈现方式                              |
| 4 | 生图比例 | 是  | chips 单选      | 1:1 / 4:3 / 9:16                                      | 1:1   | 1:1 平台主图 · 4:3 详情页横图 · 9:16 竖版主图 / 详情长图 |
| 5 | 生成张数 | 否  | chips 单选      | 1 张 / 2 张 / 4 张                                       | 1 张   | 按所选张数批量输出                               |

**计费**：单价 8 积分/张，出图张数 = 所选生成张数

> 示例：选「4 张」→ 处理内容 4 张 · 共 32 积分

## 6. 计费与积分规则

| 项目    | 规则                         |
| ----- | -------------------------- |
| 计费单位  | 张（成品图）                     |
| 单价    | 8 积分 / 张                   |
| AI卖点图 | 张数 = 所选语种数                 |
| AI细节图 | 张数 = 所选生成张数                |
| 计算公式  | 消耗积分 = 张数 × 8              |
| 扣费时机  | 提交任务时预扣                    |
| 失败返还  | 生成失败自动返还本次全部消耗，明细记一条蓝色返还记录 |
| 余额不足  | 提示前往领取每日签到积分或充值，不提交任务      |

**积分明细记录格式**

| 元素   | 说明                  | 示例                         |
| ---- | ------------------- | -------------------------- |
| 日期分组 | 按自然日分组              | 2026-10-24                 |
| 图标   | 蓝色 ↺ = 返还；红色 − = 扣减 |                            |
| 标题   | 工具名 + 状态            | 数字人口播完成                    |
| 说明行  | 时间 · 类型 · 积分        | 10-24 09:13 · 生成扣减 · 25 积分 |
| 金额   | 右侧右对齐，+ 蓝色 / − 红色   | +25 / −25                  |

## 8. 未决问题

1. **单价 8 积分/张为原型沿用截图数值**，需与定价表确认是否统一；如不同工具单价不同，需补一张"工具—单价"对照表
2. 卖点图是否支持"一次生成多版面供选择"（当前为按语种 1:1 出图）
3. 细节图「生成张数」上限是否放开到 4 张以上
4. 生成结果是否需要提供"重新生成 / 微调文案"二次编辑入口
5. 积分明细是否需要分页与筛选（按类型/时间）

# 移动端布局与间距规范（研发可落地版）

> 适用：`creation-hub/index.html` 全部页面与弹层。目标是把此前「每页写死 14 / 15 / 16px」的散点，收敛成一套可被研发直接引用的变量与规则。

## 1. 间距令牌（已写入 `:root`）

| 变量 | 值 | 用途 |
|---|---|---|
| `--pad-x` | 16px | 页面左右安全边距。顶栏、列表、卡片、贴底条、弹层统一取这个值 |
| `--pad-card` | 14px | 卡片 / 列表项内边距 |
| `--gap-sec` | 16px | 区块之间的纵向间距 |
| `--gap-item` | 10px | 列表卡片之间的间距 |
| `--gap-inline` | 8px | 行内元素（图标与文字、按钮与按钮）间距 |
| `--hit` | 44px | 最小触控热区 |

取值原则：纵向节奏按 **4 的倍数**；不再出现 1px / 3px / 13px 这类无来源的数值。

## 2. 页边距：改前 → 改后

| 页面 / 区域 | 改前 | 改后 |
|---|---|---|
| 顶栏 `.topbar` | 14px | `--pad-x` 16px（上 14 → 12，下 10 保持） |
| 首页品牌栏 `.home-top` | 14px | 16px（下 9 → 8） |
| 首页内容区 `.home-head` / `.grid` | 14px | 16px |
| 首页分类标题 `.home-sec` | **15px** | 16px（上 13 → 14） |
| 底部 CTA `.cta-bar` | 14px | 16px |
| 充值页 `.charge-scroll` | 14px | 16px |
| 充值记录 `.records-scroll` | 14px | 16px |
| 创作历史 `.hd-filters` / `.hd-scroll` | 14px | 16px |
| 图库选择 `.gl-grid` | **10px** | 16px |
| 剪切旋转 `.crop-stage` | 14px | 16px |
| 底部弹层 `.sheet` | **18px** | 16px |
| 上传弹层 `.up-sheet` | 14px | 16px |
| 聊天消息区 / 输入区 | 16 / **12px** | 16px |

**遗留的 2px 幽灵偏移全部清掉**：`.pack-title`、`.pack-sub`、`.sheet-balance`、`.chat-hero`、`.lg-balance`、`.consent`、`.pay-agree` 的 `margin … 2px …` 统一改为 0。

## 3. 触控热区

规则：视觉高度不足 44px 的元素，用 `::after{position:absolute;inset:-Npx}` 向外扩热区，**不放视觉尺寸**。

| 元素 | 原视觉高度 | 处理 |
|---|---|---|
| `.rc-tab`（充值记录筛选） | 29px | 抬到 32px，`::after` 外扩 6px → 44px |
| `.fn-chip`（聊天快捷功能） | 32px | `::after` 纵向外扩 6px → 44px |
| `.sg-btn`（签到按钮） | 34px | `::after` 外扩 5/4px → 44px |
| `.history-btn` | 34px | 已有 `::after` -4px → 42px，配合 8px 行内间距达到可点标准 |
| `.p-buy-btn` / `.points-pill` / `.icon-btn` | — | 原有 `::after` 外扩保留 |

## 4. 输入框与 iOS

iOS Safari 在输入框字号 < 16px 时会在聚焦瞬间强制放大页面，且不会自动缩回。处理：

```css
@supports (-webkit-touch-callout:none){
  .ask-input,.input-box input,.textarea{font-size:16px}
}
```

只影响触摸端，桌面预览仍是原字号，不做 `maximum-scale=1`（那会连带禁掉双指缩放，属于无障碍倒退）。

## 5. 安全区

所有贴底固定元素必须带 `env(safe-area-inset-bottom)`：`.cta-bar`、`.chat-bottom`、`.gl-bar`、`.hd-foot`、`.sheet`、`.up-sheet`、`.toast` 位置。顶部栏同理带 `env(safe-area-inset-top)`。

## 6. 本次一并修掉的问题

1. **上传弹层 padding 失效**：`.up-sheet` 与 `.sheet` 同为单类选择器，`.sheet` 写在后面直接覆盖，导致 6px/16px 的紧凑内边距从未生效。改为 `.sheet.up-sheet` 提权。
2. **320px 顶栏按钮换行**：≤360px 的媒体查询把 `.history-btn` 压成 36px 图标方块，但「充值记录」没有 `<span>` 包裹，文字被挤成两行。加 `.text-only` 例外类，窄屏保持自适应宽度。
3. **充值记录页最后一条被页脚压住**：`.hd-scroll` 底部内边距 14px → 56px，滚到底能完整露出最后一条。
4. **余额卡文案在 320px 断行错乱**：`.cb-links` 允许换行、单项 `nowrap`，累计充值单独成行右对齐。
5. **聊天快捷功能条右侧硬切**：`.fn-bar` 加渐隐遮罩与滚动尾部留白，滑动端看起来是「还有内容」而不是「被裁掉」。
6. **剪切旋转页底部留白不足**：`flow-scroll` 底部 92 → 116px，最后一排比例选项可完整滚出 CTA 之外。
